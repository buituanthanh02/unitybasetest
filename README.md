# SE7EN — Unity Gameplay Test

Bài test Unity của **Bùi Tuấn Thành**: game vượt chướng ngại vật 3D góc nhìn thứ ba, sử dụng nhân vật và bản đồ được cung cấp trong đề bài.

## Mục tiêu

Điều khiển nhân vật từ khu vực tủ đồ phòng đầu tiên đến cuối đường thông gió phòng thứ hai. Người chơi cần mở cửa, kích hoạt các bậc platform và vượt qua chướng ngại trên đường đi.

Tương tác với nút hoàn thành ở cuối màn để chiến thắng. Chạm bẫy hoặc rơi xuống khu vực nguy hiểm sẽ kết thúc lượt chơi.

## Điều khiển

| Thao tác | Điều khiển |
|---|---|
| Di chuyển | WASD |
| Nhảy | Space |
| Xoay camera | Giữ chuột trái và di chuyển chuột |
| Tương tác | Đến gần cửa hoặc nút bấm, sau đó click biểu tượng tương tác |
| Tạm dừng | Nút Pause |
| Chơi lại | Nút Reset/Restart |

## Nội dung gameplay

- Hai phòng kết nối thành một tuyến vượt chướng ngại.
- Cửa thông gió và nút bấm tương tác.
- Các bậc platform được mở bằng nút bấm.
- Chướng ngại di chuyển và platform sập sau thời gian chờ.
- Animation di chuyển, nhảy, tương tác và kết thúc lượt chơi.
- Menu chính, tạm dừng, cài đặt âm thanh và màn hình kết quả.

## Chạy bản build

**Windows Build:** [Tải bản chơi trên Google Drive](https://drive.google.com/drive/folders/1K3QnmM_Cdly2_bxueRixrTg1b4E7d68r?usp=drive_link)

Tải toàn bộ thư mục build và chạy file `.exe`. Giữ nguyên các file đi kèm và thư mục `_Data` trong cùng thư mục với file thực thi.

## Mở project

- Unity: **2022.3.62f2**
- Thêm project vào Unity Hub.
- Mở scene `MainMenu` và nhấn Play.

## Ghi chú

Project được thực hiện phục vụ bài test tuyển dụng SE7EN Game Studio. Nhân vật và bản đồ sử dụng tài nguyên được cung cấp theo đề bài; không phân phối lại cho mục đích khác.
